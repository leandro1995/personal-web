# Perfil Web – Leandro Castillo Borja

## Descripción

Este proyecto es un portafolio web personal creado para presentar de manera clara, moderna y profesional el perfil de **Leandro Castillo Borja** como desarrollador Android/Mobile. La página reúne información principal sobre su presentación profesional, experiencia, habilidades técnicas, proyectos, datos de contacto y acceso al CV.

El sitio fue diseñado con apoyo de **Stitch** y **Gemini 3.1 Pro**, utilizados como herramientas de asistencia para la creación visual, organización de secciones, estilo de interfaz y estructura general del portafolio.

## Objetivo del proyecto

El objetivo de este portafolio es contar con una página web profesional que funcione como carta de presentación digital, permitiendo mostrar de forma ordenada las capacidades técnicas, experiencia y enfoque profesional de Leandro Castillo Borja en el desarrollo móvil, especialmente en el ecosistema Android.

## Características principales

- Diseño moderno con enfoque tecnológico y profesional.
- Interfaz responsive adaptable a distintos tamaños de pantalla.
- Presentación del perfil profesional como desarrollador Android/Mobile.
- Secciones organizadas para experiencia, habilidades, proyectos y contacto.
- Inclusión de CV descargable en formato PDF.
- Uso de recursos visuales propios, como ilustraciones SVG.
- Estructura web ligera, ideal para publicación en GitHub Pages, Vercel, Netlify u otro servicio de hosting estático.
- Código organizado para facilitar mantenimiento y futuras mejoras.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- TypeScript
- Vite
- SVG para recursos gráficos
- PDF para el CV profesional
- Stitch y Gemini 3.1 Pro como apoyo en el diseño y generación inicial de la interfaz
